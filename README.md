# Zizo World — عالم زيزو

تطبيق أندرويد للأطفال من ٤ إلى ٦ سنوات مع زيزو الفيل: الحروف والأرقام بالعربي والإنجليزي، والألوان والأشكال والحيوانات.

- `www/` صفحات التطبيق نفسه (الترحيب باسم الطفل، الحروف، الأرقام، اكتشف، رحلة زيزو وتحدّي اليوم والألعاب، الرسم، متجر زيزو الذي يُشترى فيه بالنجوم فقط) والخطوط
- `android-overlay/` الأيقونات وشاشة البداية
- `store/` صور المتجر: الأيقونة ٥١٢، الصورة الرئيسية، ولقطات الشاشة
- مفتاح توقيع التطبيق محفوظ كسر في GitHub (`KEYSTORE_BASE64` و`KEYSTORE_PASSWORD`) وليس داخل الملفات، لأن المستودع عام. احتفظ بنسخة من الملف `upload.jks` وكلمة سره عندك، فكل تحديث على Google Play يحتاجه

## كيف يُبنى التطبيق

كل تعديل يُرفع إلى هذا المستودع يبني التطبيق تلقائياً من تبويب **Actions**.
بعد انتهاء البناء تجد نسخة التجربة دائماً على هذا الرابط، وتُثبَّت فوق النسخة السابقة:

https://github.com/zwyd4583-jpg/huroof-zizo/releases/download/test-build/zizo-world-test.apk

أما ملف Google Play (`zizo-world-vN.aab`) فيظهر في قسم **Artifacts** من آخر تشغيل، فقط بعد إضافة كلمة سر المفتاح.

## متابعة العمل مع Claude Code

ملف `CLAUDE.md` يشرح المشروع كله لـ Claude: طريقة البناء، صوت زيزو، قواعد السلاسة، والاختبارات (`tests/`). والأدوات المساعدة في `tools/`.

## مفتاح التوقيع

من **Settings ← Secrets and variables ← Actions** يجب أن يوجد سرّان:
- `KEYSTORE_BASE64` محتوى ملف المفتاح
- `KEYSTORE_PASSWORD` كلمة سر المفتاح

بدونهما يُبنى ملف التجربة فقط، وليس ملف Google Play.
